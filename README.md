## Français

Une barre des tâches pour Windows 11, inspirée du Liquid Glass.

### Fonctionnalités

- Apparence adaptée au thème Windows, opacité et largeur réglables. Taille globale de 25 à 200 %.
- Applications et dossiers réorganisables par glisser-déposer, avec animations à l’ajout et au retrait.
- Dossiers avec une grille 3 × 3, plusieurs pages et miniature synchronisée.
- Aperçus des fenêtres, indicateurs des applications ouvertes et carrousel lorsque la place manque.
- Accès aux panneaux natifs de Windows : calendrier, réglages rapides et icônes cachées.
- Masquage en plein écran et démarrage automatique en option.

### Installation

1. Télécharger `GlassDock-v1.1.0.zip` ou `GlassDock-v1.1.0.rar` depuis **Releases**.
2. Extraire tous les fichiers dans un même dossier.
3. Lancer `GlassDock.exe`.

**Prérequis :** Windows 11 x64 et .NET Desktop Runtime 10.

### Utilisation

Glisser une application sur une autre pour créer un dossier. Cliquer sur le titre du dossier pour le renommer. Faire un clic droit sur une application pour la fermer ou terminer sa tâche.

Faire un clic droit sur la barre pour accéder aux paramètres ou au Gestionnaire des tâches. Dans les paramètres, le bouton ordinateur active le démarrage automatique ; le bouton alimentation quitte GlassDock et rétablit la barre Windows. La croix ferme uniquement les paramètres.

### Compilation

Avec le SDK .NET 10 sous Windows, depuis le dossier contenant `GlassDock.csproj` :

```powershell
dotnet publish GlassDock.csproj -c Release -r win-x64 --self-contained false -o dist
```

Les fichiers prêts à lancer sont générés dans `dist`.

## English

A Windows 11 taskbar inspired by Liquid Glass.

### Features

- Appearance follows the Windows theme, with adjustable opacity and width. Global scale from 25 to 200%.
- Drag and drop to reorder apps and folders, with animations when icons are added or removed.
- Folders with a 3 × 3 grid, multiple pages, and a synchronized preview.
- Window previews, running app indicators, and a carousel when space is limited.
- Access to native Windows panels: calendar, quick settings, and hidden tray icons.
- Fullscreen hiding and optional automatic startup.

### Installation

1. Download `GlassDock-v1.1.0.zip` or `GlassDock-v1.1.0.rar` from **Releases**.
2. Extract all files into the same folder.
3. Run `GlassDock.exe`.

**Requirements :** Windows 11 x64 and .NET Desktop Runtime 10.

### Usage

Drag an app onto another to create a folder. Click the folder title to rename it. Right-click an app to close its windows or end its task.

Right-click the dock to open settings or Task Manager. In settings, the computer button toggles automatic startup; the power button quits GlassDock and restores the Windows taskbar. The cross closes settings only.

### Build

With the .NET 10 SDK on Windows, from the folder containing `GlassDock.csproj`:

```powershell
dotnet publish GlassDock.csproj -c Release -r win-x64 --self-contained false -o dist
```

Ready-to-run files are generated in `dist`.

## 日本語

Liquid Glass に着想を得た Windows 11 用タスクバー。

### 機能

- Windows のテーマに合わせた外観。不透明度と幅を調整でき、全体の倍率は 25〜200 % に設定できます。
- ドラッグ＆ドロップによるアプリとフォルダーの並べ替え。アイコンの追加・削除時にアニメーションを表示します。
- 3 × 3 のグリッド、複数ページ、配置と連動する縮小プレビューを備えたフォルダー。
- ウィンドウのプレビュー、起動中アプリのインジケーター、スペース不足時のカルーセル。
- Windows 標準のカレンダー、クイック設定、非表示アイコンにアクセス。
- 全画面表示時の自動非表示と、任意の自動起動設定。

### インストール

1. **Releases** から `GlassDock-v1.1.0.zip` または `GlassDock-v1.1.0.rar` をダウンロードします。
2. すべてのファイルを同じフォルダーに展開します。
3. `GlassDock.exe` を実行します。

**動作要件 :** Windows 11 x64 および .NET Desktop Runtime 10。

### 使い方

アプリを別のアプリにドラッグするとフォルダーを作成できます。フォルダーのタイトルをクリックすると名前を変更できます。アプリを右クリックすると、ウィンドウを閉じたりプロセスを終了したりできます。

バーを右クリックすると、設定またはタスク マネージャーを開けます。設定のコンピューターアイコンで自動起動を切り替え、電源ボタンで GlassDock を終了して Windows のタスクバーを復元します。× ボタンは設定画面のみを閉じます。

### ビルド

Windows に .NET 10 SDK をインストールし、`GlassDock.csproj` のあるフォルダーで実行します。

```powershell
dotnet publish GlassDock.csproj -c Release -r win-x64 --self-contained false -o dist
```

実行用ファイルは `dist` に生成されます。
